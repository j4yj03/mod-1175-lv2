# data/ — normative Modell- und Presetdaten

`model.json`, `parameters.json`, `transformers.json` und `presets.json` sind
normativ: Ports, JSFX-Slider, TTL, Presets und GUI werden daraus von
`tools/generate.py` erzeugt. Änderungen immer hier, nie in den generierten
Artefakten. Details: [DSP](DSP.md).
